# Hi, I'm Ayush

I'm a full stack engineer in Bangalore, currently leading the engineering team at Tech Japan / Talendy. I work with TypeScript, React, Next.js, Python and PostgreSQL.

## Things I've built

- [AgentClash](https://github.com/agentclash/agentclash): Run AI agents on the same tasks, compare their results and keep a record of what each one did. Failed runs can become regression checks in CI.
- [SolSign](https://github.com/AyushRajSinghParihar/SolSign): An e-signature app on Solana that mints signed documents as NFTs. Supported by a $3,000 Superteam grant.
- [flatfind](https://github.com/AyushRajSinghParihar/flatfind): A Python CLI for finding flats in Bangalore through NoBroker. Search in plain English, score listing photos, or use it through an MCP server.
- [InsightAI](https://github.com/AyushRajSinghParihar/InsightAI): A Streamlit app that reads university question papers from PDFs and generates answers with Groq and Llama.
- [Rockefeller](https://github.com/AyushRajSinghParihar/rockefeller): An agent skill for working through business decisions using operating costs, cash flow and the numbers behind growth.
