# Hi, I'm Ayush

I'm a full stack engineer at Talendy, based in Bangalore. I work with TypeScript, React, Next.js, Python and PostgreSQL.

## Main projects

### [AgentClash](https://github.com/agentclash/agentclash)

An open-source platform for evaluating AI agents on real tasks. It runs agents on the same workloads, records their execution traces, and compares correctness, cost, latency and tool use. Failed runs can become regression checks in CI.

Built with Go, Next.js, PostgreSQL, Temporal and Redis. [Website and docs](https://www.agentclash.dev).

### [SolSign](https://github.com/AyushRajSinghParihar/SolSign)

An e-signature app built on Solana. It supports reusable signing workflows and profile autofill, then mints signed documents as NFTs with metadata stored on Arweave. Supported by a Superteam grant.

## Random projects

Personal tools and experiments that aren't production projects.

- [flatfind](https://github.com/AyushRajSinghParihar/flatfind): A Python CLI for finding flats in Bangalore through NoBroker, with plain-English searches, listing-photo scoring and an MCP server.
- [InsightAI](https://github.com/AyushRajSinghParihar/InsightAI): A Streamlit app that reads university question papers from PDFs and generates answers with Groq and Llama.
- [Rockefeller](https://github.com/AyushRajSinghParihar/rockefeller): An agent skill for working through business decisions using operating costs, cash flow and the numbers behind growth.
- [claim-verifier](https://github.com/AyushRajSinghParihar/claim-verifier): An agent skill for checking articles against their sources, including calculations and factual changes introduced during editing.
- [blog-publisher](https://github.com/AyushRajSinghParihar/blog-publisher): An agent skill for following a site's publishing workflow and checking that the published page matches the reviewed article.
- [Focus Board](https://github.com/AyushRajSinghParihar/productivity): A fullscreen task dashboard with a countdown timer, a daily planner and session history. Data stays in the browser.
- [Expense tracker](https://github.com/AyushRajSinghParihar/college-project): A college project for tracking income and expenses, charting spending by category and searching past transactions. Built with Next.js and localStorage.
- [Greenify](https://github.com/AyushRajSinghParihar/Greenify): A waste-sorting app using a CNN trained on 8,000 samples to classify waste into 11 categories, with a React frontend and Django backend.
